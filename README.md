An entry for the make.fun bounty **The One-Line Laugh**: one funny line, a
single sentence of at most 200 characters, written by `main.py` to
`entry.txt`. The line leans on a surprise twist at the end — a smart speaker
asked for something relaxing answers with the least relaxing sound of all.

> I asked my smart speaker to play something relaxing, so it read out my bank balance.

## Run

```sh
python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` when that variable is set,
or to `output/entry.txt` otherwise. Python standard library only.
